# Developer documentation

> This reference describes the 7.1 development branches. Use an artifact containing those changes; a published 7.0 build may expose fewer features. Standard-only interactions are labelled explicitly.

The developer reference is available at [API](API.md). It includes creation and conversion signatures, wrappers, texture data, cancellation and event targets, and Folia ownership requirements.

For shader integration refresh methods, see [Postprocessing shaders](postprocessing‐shaders.md#updating-integration-state).
